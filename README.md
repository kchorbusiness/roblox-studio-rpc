# Roblox Studio RPC
> Discord Rich Presence for Roblox Studio — shows your current game, script, and line number in real time.

---

## What it shows
Blackout Protocol [CAS]

Editing: NPCModule — Line 247

1 hour 23 minutes

---

## Requirements
- Windows 10/11
- Discord desktop app (must be running)
- Roblox Studio

---

## Installation

1. Download and run `Roblox Studio RPC Setup 1.0.0.exe` from [Releases](https://github.com/kchorbusiness/roblox-studio-rpc/releases)
2. The app starts automatically in your system tray
3. Install the Roblox Studio plugin from the [Creator Store](https://create.roblox.com/store/asset/80748890788569)
4. In Roblox Studio → **File → Studio Settings → Security** → enable **Allow HTTP Requests**
5. Restart Studio — done

---

## Tray Icon Status

| Status | Meaning |
|--------|---------|
| `Discord: Connected (username)` | Everything working |
| `Discord: Disconnected` | Open Discord |
| `Studio: Idle` | No script open in Studio |
